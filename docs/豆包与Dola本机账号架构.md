# 豆包与 Dola 本机账号

豆包、Dola 是用户自己的平台账号，在桌面客户端内嵌的平台页面登录，生成请求经该页面发出，不经过妙图云端模型渠道。代码在 `desktop/local-media/`。

## 账号槽位

- 每个妙图账户、每个平台各自维护账号槽位列表。
- 每个槽位用不可变随机 ID，拥有独立的 Electron 持久化 Session、Cookie 和网页缓存。
- 槽位只保存用户可编辑的名称、创建时间和本机 Session 分区，不保存平台密码或 Cookie 明文。
- 默认槽位固定为 `default`，沿用已有的平台登录分区，升级后不要求重新登录。

## 选择与任务归属

- 节点只用当前选中的平台账号读取模型菜单、参数和额度。
- 提交时把槽位 ID 和显示名称写入任务 `routeState`；之后查询、取消、关联和下载都按任务里的槽位，不跟随后来切换的默认账号。没有槽位字段的任务按 `default` 处理。
- 槽位有未结束任务时，禁止清除或删除该槽位。

## 模型与参数

- 只有用户登录了对应平台，节点才显示该平台的模型；未登录时提示在妙图中登录该平台，不显示预置模型。
- 已登录但账号菜单还没返回时，先用下表预置值显示模型、时长、比例和清晰度；菜单返回后全部以当前账号的结果覆盖，不保留账号没有开放的型号或选项。
- 预置只用于立即显示，不代表该账号有提交权限。真正发送要求已读到当前账号菜单，并在平台页面回读所选值与实际出站参数一致；页面或菜单变化时不静默换成别的模型。
- 网页没有的档位（例如 480p）不能伪装成可选按钮，更不能绕过页面直接提交。网页没有独立尺寸控件时，尺寸显示为“跟随平台”。
- 设置页展示节点模型 ID、平台模型 ID、输入类型、时长、比例和分辨率。

## 网络

- 软件不保存、判断或限制用户 IP，没有“某地区用户才能用”的业务分支。地区限制、登录挑战和平台额度由平台页面返回，妙图只显示真实状态并停止发送，不伪造连接成功。
- 豆包优先用能正常打开豆包页面的大陆网络。Dola 需要平台支持的地区，而且妙图进程要真的经过该地区网络：Clash Verge 只选节点、没开系统代理或 TUN 时，Electron 仍可能直连。
- Dola 没有公开国家清单；日本出口能进入创作页，美国出口会跳到 `security/region-restricted`，公开资料一致指出美国、加拿大、澳大利亚、中国大陆不可用。
- 测试某个出口用独立的临时 mihomo 端口，不改用户全局节点、系统代理或 TUN。
- 平台页面能加载不等于请求能成功：至少检查页面、登录、创作菜单和目标上游能通信；不发生成请求也能完成通信验收。
