# 豆包与 Dola 本机账号架构

## 账号模型

- 每个妙图账户、每个平台分别维护账号槽位列表。
- 每个槽位使用不可变随机 ID，并拥有独立的 Electron 持久化 Session、Cookie 和网页缓存。
- 槽位只保存用户可编辑的名称、创建时间和本机 Session 分区，不保存平台密码或 Cookie 明文。
- 默认槽位固定为 `default`，继续使用升级前已有的平台登录分区，避免升级后要求重新登录。

## 选择与任务归属

- 节点只使用当前选中的平台账号读取模型菜单、参数和额度。
- 提交时把槽位 ID 和显示名称写入任务 `routeState`。之后查询、取消、关联和下载都按任务里的槽位读取，不跟随后来切换的默认账号。
- 旧任务没有槽位字段时按 `default` 处理。
- 一个槽位有未结束任务时，禁止清除或删除该槽位，避免结果失去归属。

## 模型与参数展示

- 模型列表来自当前平台账号实际返回的创作菜单，不使用固定地区或固定套餐清单代替。
- 设置页同时展示节点模型 ID、平台模型 ID、输入类型、时长、比例和分辨率。
- 节点提交前继续按同一份菜单校验模型与参数；页面和菜单变化时不会静默换成别的模型。

## 网络边界

- 软件不保存、判断或限制用户 IP，也不包含“某地区用户才能使用”的业务分支。
- 测试时只需让当前平台访问可用网络：豆包按实际支持的网络验证，Dola 按平台允许的地区验证。
- 地区限制、登录挑战或平台额度由平台页面返回；妙图只显示真实状态并停止发送，不伪造连接成功。
