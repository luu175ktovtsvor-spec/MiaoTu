# 线上排查与修复流程

服务器是云端账号、积分、生成记录、媒体权限和服务运行状态的事实来源，不能用本地数据库或 Vite 代替。桌面项目、平台账号 Session、本机媒体和保存状态则要看对应的本机 App/workspace，不能凭服务器正常认定桌面正常。部署细节见 [deploy/native/README.md](../deploy/native/README.md)。

## 只读检查

```bash
deploy/inspect.sh            # 本机执行，内部 SSH 到生产运行 inspect-native.py
```

报告服务状态、实际 PID 与工作目录、端口健康、账号库计数和余额不变量。余额不变量逐个账号比较 `users.points` 和账本累计：账本必须能解释当前余额，总额相等不能掩盖账号级差异。HTTP 结果里的“未知”表示这次没读到，不代表正常；`401`、`404`、`405` 是真实响应，不代表服务挂了。

## 常见问题

| 现象 | 先看什么 |
| --- | --- |
| 站点 502 | `inspect.sh` 的四个端口健康和服务状态，`journalctl -u miaoimg`；先分清是页面服务还是内层 API |
| 生成卡住 | 任务是否一直 `queued/running`、API 4175 健康、日志异常；不要再发一次生成“试一下” |
| 某人积分不对 | 余额不变量里该账号的余额、账本累计和差额；不要先手改余额 |
| 灵感库没更新 | `/opt/miaoimg/.oip/runtime-data/sync-status.json` 的状态与原因，`systemctl status miaoimg-sync.timer` |
| 想知道运行的是哪一版 | 主进程实际工作目录和 `OIP_RUNTIME_REVISION`，不以本地 Git 或 `current` 链接代替 |

## 修复流程

用户要求处理线上问题时，按 **定位 → 最小修复 → 候选验收 → 可回滚发布 → 生产实测 → 清理 → 简短汇报** 做到交付。完成该问题所需的最小部署和最少真实调用已在授权范围内，不重复询问；超出范围、破坏性操作或缺少必要信息时再确认。

1. **沿真实请求链定位**：账号、客户端版本、所选模型/模式、实际请求体，再查服务端、模型网关与上游账号、模型响应、结果取回和画布写入。区分事实和推测，不凭错误码或通用文档下结论。
2. **最小修复**：从 main 的明确提交修改，不带入其他任务的未完成改动。保持用户选择的模型和素材语义，不偷换模型，不用拉伸、裁剪、重编码掩盖上游参数不生效；有上游限制时给出明确可用的入口，并尽量在扣费前拦下无效请求。
3. **发布**：按 deploy/native/README.md 的候选与切换步骤执行，保留回滚点。健康检查和模块自检通过不等于已修复。
4. **生产实测**：用用户授权的账号从登录表单进入，在本轮新建的画布（或用户指定的画布上新增节点）选择模型、模式和参数，提交真实生成，次数、时长、分辨率取能验证问题的最小值。
5. **跟到终态**：以实际任务状态为准，不设本地总等待时长或轮询次数上限；单次查询可以超时，但只能继续查询或取回同一请求。HTTP 200/202、任务 ID 或提交成功都不是生成成功。核对原始产物：图片看实际尺寸和内容，视频看尺寸、时长、播放和解码，比例问题核对原始媒体尺寸；再确认写入画布、重开后仍可读取。单个模型或模式通过不代表全部通过。
6. **清理**：真实调用的产物、节点、媒体、生成记录和扣费账本默认保留，只有用户明确要求才删。只清理未使用的临时素材、临时构建目录和自己启动的进程；退出自己的登录态。
7. **汇报**：原因、是否上线、实测结果、必要费用和仍未验证的限制。只有构建、健康检查或接口成功时，不能说真实验收完成。

## 红线

- **只读检查保持只读**：不给检查脚本加启动、重启、删除或改库的逻辑。需要写入、迁移或同步时用对应的明确脚本，并先说明影响范围。
- **存量迁移**：没有明确授权不运行 `scripts/migrate-projects.ts --apply`、`scripts/migrate-media-blobs.ts` 或任何存量数据修复；需要时先 `--report`，确认备份和回滚路径后单独授权。
- **网络暴露**：候选端口只绑 `127.0.0.1`，本机通过 `ssh -L` 隧道访问，不为方便临时开放安全组。
- **凭据**：不把 `OIP_ADMIN_PASSWORD`、任何 `*_KEY`、`*_TOKEN`、`*_SECRET` 或密钥文件内容打印到终端、报告、截图、Git 或发布包；输出中出现的脱敏标记保持原样。
- **真实请求**：只读排查不发生成或支付请求；真实上游调用消耗额度，真实支付有外部副作用，都要另行授权。
