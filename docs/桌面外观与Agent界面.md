# 桌面外观与 Agent 界面

## 统一浅色

`desktop/renderer/src/clientAppearance.ts` 是 React 外壳、Vue 画布和 body 浮层的配色来源。标准浅色使用中性灰白层次：

| 语义 | 色值 |
| --- | --- |
| 页面 | `#f7f7f7` |
| 画布 | `#f5f5f5` |
| 面板、节点与浮层 | `#ffffff` |
| 正文、控件文字 | `#141414`、`#262626` |
| 次要文字 | 黑色 55% |
| 细边框、强调边框 | `#e3e3e3`、`#c4c4c4` |
| 网格点 | `#dedede` |
| 悬停背景 | 黑色 5% |

`canvas-look.css` 的标准浅色分支从 html 继承共享颜色，再映射到 `--canvas-*`、`--el-*`。不要在外壳和画布分别维护一套偏色的白色。设置、下拉、Agent 等挂到 body 的界面也使用同一组语义色；素材图片和视频不做颜色滤镜。

外观保留四种模式：跟随系统、浅色、深色、自定义。只有跟随系统监听操作系统明暗变化；手动浅色或深色不被系统变化覆盖。标准浅色不会覆盖用户选择的强调色，自定义背景沿用原算法。验证时分别检查 html token、body 继承值和实际绘制背景，不能只比较 TypeScript 返回值。

## Agent 对话

- 默认浮窗 400×640，宽高受工作区边界约束；桌面未停靠浮窗圆角 28px，窄屏保持 16px，原停靠与调整尺寸行为保留。
- 标题集成历史下拉，历史可本地搜索，按界面语言显示日期；已有重命名、删除、子任务和加载状态保留。
- 空态靠近输入区。建议以紧凑按钮放在输入框内，点击只填入草稿，不发送消息。
- 输入区圆角 20px，编辑区最低 64px。正文 14px / 25px，用户消息保留独立气泡。
- 思考过程、消息操作、流式、停止、追加输入与错误继续由真实状态驱动。
- 成功且折叠的工具显示轻量摘要；运行、失败、中断和结果待确认状态保持可见，展开后仍可查看详情。

Agent 外层样式需明确高于通用浮层选择器的优先级。通用 `:is(...)` 包含双 class 时，可能覆盖组件里的单 class 规则；应在实际 Electron 中核对圆角和边框，不能以 CSS 文件中的声明代替验收结果。

## 验证边界

使用独立 profile/workspace，关闭正式更新与生成。界面验收可检查空态、草稿填入、历史下拉、停靠、尺寸、系统外观变化和中英文；付费模型调用遵循任务单独授权。工具协议使用现有 `verify:mcp` 与灵感库契约检查，素材与内容更新按[灵感库与内容发布](灵感库与内容发布.md)执行。
