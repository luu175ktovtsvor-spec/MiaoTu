# 妙图桌面版本发布与包命名

完整开发隔离、真包启动、云端打包、更新验收与发布边界见[开发隔离与桌面发布](开发隔离与桌面发布.md)。本页的旧版本号是历史记录与命名示例，不代表当前正式版本。

桌面版本使用三段式版本号 `主版本.次版本.修订版本`。一次已经进入正式包的用户可见修改，后续再追加用户可见修改，就递增修订版本；不能把两批不同验收批次继续塞进同一个版本号。

本轮的版本关系是：Claude 完成并纳入的第一批桌面修改属于 `3.1.1`；Codex 在其后追加的平台标签间距修改和对应验收收尾属于 `3.1.2`；随后修复“项目索引残缺导致最近项目无法删除”属于 `3.1.3`；选中平台标签文字对比度修复属于 `3.1.4`；豆包视频自动确认与取回、模型参数展示、多平台账号槽位属于 `3.1.5`；Dola 新版参数面板、图片取回和路由回执兼容属于 `3.1.6`。每一批用户可见修改都必须重新打包，不能只把旧安装包改名。

正式安装包文件名必须带版本号：

- `妙图-3.1.2-arm64.dmg`
- `妙图-3.1.2-x64.dmg`
- `妙图-3.1.2-Windows-x64.exe`
- `妙图-3.1.2-arm64.zip`、`妙图-3.1.2-x64.zip`

官网更新源还提供便于下载页使用的版本化别名：

- `miaoimg-desktop-mac-arm64-3.1.2.dmg`
- `miaoimg-desktop-mac-x64-3.1.2.dmg`
- `miaoimg-desktop-windows-3.1.2.exe`

旧的 `miaoimg-desktop-mac-arm64.dmg`、`miaoimg-desktop-mac-x64.dmg` 和 `miaoimg-desktop-windows.exe` 只作为兼容入口，发布时跟随当前版本更新，不作为版本归档名称。macOS 首次安装脚本优先使用版本化文件名。

每次发布按这个顺序执行：先在当前源码和真实页面验收，再从明确提交打 Mac 与 Windows 包并分别启动验收；核对 `latest-mac.yml`、`latest.yml` 的版本、文件大小和 SHA-512；先传到服务器 staging，最后才切换两个 `latest*.yml`；公网回读版本化下载地址和兼容入口；确认完成后删除 GitHub 临时构建/验收 Release，并把临时公开的 GitHub 仓库改回私有。

`3.1.7` 提前展示豆包与 Dola 已核对参数，账号菜单返回后覆盖预置，并修正 Dola 的 4–10 秒时长及自动比例。

macOS 签名、公证、官网版本与安装脚本、历史版本及是否重打包的完整约束见 [macOS安装与发布规范](macOS安装与发布规范.md)。正式更新脚本会一并发布读取线上版本的安装脚本；不再通过手填脚本版本号追赶发布。
