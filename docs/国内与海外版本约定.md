# 国内版与海外版：目录、仓库和发布约定

这两条产品线使用两个独立 GitHub 仓库和两个独立本地 Git 仓库分别维护。项目正式中文名是“妙图”；沟通中的“秒图”按“妙图”理解。

| 项目 | 国内版 | 海外版 |
| --- | --- | --- |
| 本地工作目录 | `ChineseMain/` | `OverseasMain/` |
| Git 分支 | `ChineseMain` | `OverseasMain` |
| 产品显示名称 | 妙图 | MiaoImg |
| GitHub 仓库地址名 | `MiaoTu` | `MiaoImg` |
| GitHub 临时附件前缀（ASCII 传输） | `MiaoTu-`，正式交付恢复为“妙图-” | `MiaoImg-` |
| 官方网站 | `https://miaoimg.cn` | `https://miaoimg.com` |
| 服务部署区域 | 美国 | 英国 |
| Windows 安装包示例 | `妙图-3.2.1-Windows-x64.exe` | `MiaoImg-3.2.1-Windows-x64.exe` |
| Mac Apple 芯片安装包示例 | `妙图-3.2.1-arm64.dmg`、`妙图-3.2.1-arm64.zip` | `MiaoImg-3.2.1-arm64.dmg`、`MiaoImg-3.2.1-arm64.zip` |
| Mac Intel 安装包示例 | `妙图-3.2.1-x64.dmg`、`妙图-3.2.1-x64.zip` | `MiaoImg-3.2.1-x64.dmg`、`MiaoImg-3.2.1-x64.zip` |
| 已确定的管理后台地址 | `https://admin.miaoimg.cn` | 待海外环境单独确定 |
| 已确定的桌面更新源 | `https://miaoimg.cn/desktop-downloads/updates/` | 随海外环境单独配置，不使用国内更新源 |

表中的版本号只是命名示例，实际使用各产品线本次发布的版本号。GitHub 地址名只支持 ASCII，因此国内使用拼音 `MiaoTu`，产品界面与用户安装包仍使用中文“妙图”。

## 执行规则

- 国内仓库是 `MiaoTu`，默认分支 `ChineseMain`；海外仓库是 `MiaoImg`，默认分支 `OverseasMain`。禁止把海外版长期放在国内仓库的一个分支里，也不共用 Git 远端配置。

- 每次开发、提交、构建或发布前，核对当前文件夹、Git 分支、GitHub 远端、产品名称与目标服务器，按同一列执行。
- 国内版继续使用美国环境和 miaoimg.cn。海外版面向英国环境和 miaoimg.com，独立接入；复制代码和创建分支不代表海外服务已经上线。
- 海外管理后台地址、接口配置、应用标识及更新源，在海外实际接入时确定；不臆造英国服务器 IP，不沿用国内的账号库、支付或更新配置冒充海外环境。
- 国内部署与海外部署互不覆盖。更新记录、安装包、网站下载和客户端更新元数据，必须对应同一产品线和实际发布版本。
- 国内用户拿到的正式安装包使用“妙图-”前缀，海外包使用“MiaoImg-”前缀；Mac 与 Windows 一致。临时构建传输名称如有工具限制，正式交付前必须恢复对应产品名，并重新核对元数据中的文件名。
- Git 只保留软件运行、构建、发布和维护必需的代码、资源与长期文档。参考源码、本地创作资料和临时产物放在仓库外。
- 每次实际发布与当前仓库/环境接入状态写入仓库外 `本地资料/开发记录/`；这份约定文档本身不作为某个网站、服务器或签名包已经上线的证明。
