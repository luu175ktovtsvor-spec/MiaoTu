# 本机工具与依赖共用说明

Skill 保存完整创作方法、安装说明、命令、参数、脚本与参考。多个 Skill 用到同一工具时，复用同一个已安装程序和兼容环境，不为每个 Skill 再创建同名工具或重复安装。

## 统一执行入口

桌面聊天固定使用创建时的本机工作目录，子任务继承，重启后保留。设置中的默认文件夹只影响新聊天；当前聊天的相对路径、项目说明和本地技能都从绑定目录解析。其他位置用明确路径，不能因默认设置变化自行切换。跨设备恢复的聊天使用该设备的默认目录，不照搬另一台电脑的路径。

以下本机入口仅适用于当前会话确实提供相应工具的桌面版，并须获得本机操作授权。网页版共享创作方法和文档，但不因此获得用户电脑权限；网页仅使用已提供的画布、工作区、网页检索及媒体工具。需要本地软件的步骤保留方案和待办，告知用户在桌面版继续或导入已经处理好的素材；不要调用不存在的工具，也不要在运行网页服务的机器上安装用户任务依赖。

| 需要做什么 | 使用入口 |
| --- | --- |
| 读写、编辑、列目录、查文件、搜正文 | read / write / edit / ls / find / grep |
| Git、Python、Node.js、包管理器、媒体和三维软件 | bash；Windows 可用 powershell。Git 等是本机命令，不必再创建同名 Agent 工具 |
| 网页浏览、点击、填写、截图 | browser，使用已安装 Chrome 或 Edge，默认无头后台运行；需要用户查看或登录时 open 设置 visible:true |
| 查找常用本机依赖 | localToolInfo({tool:"python"}) 等；按实际需要查，不必全盘扫描 |
| 已导入画布素材的探测、抽帧与合成 | probeMedia / inspectVideo / ffprobe / ffmpeg，按当前工具 schema 调用 |
| 本机任意路径、复杂字幕、动效、脚本及外部软件 | 通过 bash / powershell 调用真实本机程序；不把工作区 ffmpeg 包装器的路径限制套到本机命令 |
| 写回画布、保存工作区与展示产物 | 当前画布和工作区工具，确认真实文件导入后再报告 |

localToolInfo 支持 video、python、node、npm、git、ffmpeg、ffprobe、blender、yt-dlp、uv、imagemagick、sox、whisper、tesseract。它只查常用路径，未找到时继续检查用户给出的安装位置；其他工具使用 command -v / Get-Command 等正常发现，不假装已经安装。

文件搜索先从用户指定目录或项目目录开始，再按任务需要扩大范围；没有找到不能宣称全机不存在。find 使用 glob，查找文件及文件夹，返回绝对路径，支持 ~/ 路径；grep 可按普通文本或正则搜索，支持 glob 筛选和忽略大小写。两者默认返回 100 项、最多 500 项；limitReached 表示需要缩小范围。complete=false、stopReason 或 skipped 表示范围未查完、受限或被跳过，不能报告全机不存在；先缩小到指定目录再继续。默认跳过符号链接、.git、node_modules 和废纸篓；grep 跳过大于 2 MiB 的文件及检测为二进制的文件。需要搜索这些范围时使用已授权本机命令，明确范围，不无差别扫描整台电脑。PDF、图片文字、声音和视频内容需要相应解析或识别软件，不是 grep 的文本搜索能力。

grep 支持 UTF-8 和带 BOM 编码标记的 UTF-16 文本；其他编码不自动猜测。长行只返回首次命中附近约 1000 字符的片段，用省略号标明省略部分，完整内容按返回的路径和行号读取；不能把片段当作整行。已知文件被跳过时，按实际格式使用合适的解码或解析工具，保留源文件。

参数以本次工具 schema 为准，例如 edit 当前使用 `{path,edits:[{oldText,newText}]}`，不能沿用旧版顶层 oldText/newText 写法。Windows 的 powershell 是独立入口，bash 仍需本机已有 Bash；不能假设所有电脑都有相同命令或路径。

## 已有媒体的保真处理

- 先探测视频编码、分辨率、帧率及音频编码、采样率、声道。裁切、提取和兼容素材拼接默认复制原始流；用户说“约几秒”时，不为凑整数时长默认重编码整片。关键帧、音频包边界导致的实际时长差异应如实报告。
- 保留原声不仅是不换音乐。不要默认把已有音频再次压成 AAC、归一化音量、重采样或改变声道；画面需要转码时，单独保留兼容的原音轨。音频相同参数时先尝试复制与拼接，核对音频包载荷和实际播放。
- 必须混音、加滤镜、变速或音频格式不兼容时，会改变音频数据；先保留无损结果，再根据用户要求与播放兼容性说明取舍。不能把重新编码的声音称为“原始流未变”。
- 原文件不覆盖，结果使用独立输出路径。产物必须探测并解码检查；拼接还要检查接点前后画面与音频时间戳，不能只凭命令退出成功交付。做完将实际文件导入画布，不能用占位节点代替成果。

## 网页任务与浏览器

搜索资料先用 webSearch，已知网址先用 webFetch 读取正文；这些工具和本机文件读写、命令都不要求弹出浏览器。动态网页或点击、填写等操作再使用 browser。默认无头模式仍会运行真正的浏览器，具有网络和资源开销，并不保证能绕过网站验证。

webFetch 每次最多返回 20000 字符。有 nextOffset 时，沿用返回的 url、contentHash，并把 nextOffset 作为 offset 继续读取；按任务需要读取后文，不能把首页截断内容说成完整网页。收到“网页内容已变化”时，从开头重新读取，不拼接不同版本。单次网页下载仍限制 2MB，分段读取不绕过下载限制。

需要用户查看、登录或人工处理时才新建 visible:true 的可见会话。已有会话省略 visible 以继续使用原模式；切换模式必须先关闭再新建，会丢失当前临时会话的登录态、标签页和未提交表单，先判断能否安全重开。工具不读取用户日常浏览器资料。使用最新快照中的 ref；任务结束 close，撤销本机授权关闭工具浏览器。不要因为一个搜索服务没有结果就断言互联网没有资料；可以调整查询、读取已知可信来源或用浏览器核实，验证失败则如实报告。

## 安装、配置与复用

1. 首次本机授权后，按用户实际任务读取所需文件和调用命令。网页端没有本机入口时，不把网页执行环境当用户电脑。
2. 先检查程序位置、版本与依赖，再阅读原方法。完整保留 Skill 的安装与使用步骤，不因为妙图未预装就省略。
3. 妙图不在启动、切换 Skill 或扫描目录时自动下载依赖。任务需要时，Agent 可在用户授权范围内按原文步骤准备、安装、配置和运行；优先当前项目的虚拟环境、本地包与输出目录。用户指定已有环境则复用。
4. 不顺便升级全机软件或替换不相关环境。需要额外账号、付费、管理员权限或超出任务范围时说明具体缺项，由用户决定；已有任务授权不重复索要。
5. 示例里的中性命令不是可执行文件。视频配方中的 video-tool、@video-tool/ 和 VIDEO_* 先由 localToolInfo({tool:"video"}) 获取实际映射，命令、包名、脚本导入和变量一起替换；不要搜索或安装字面占位符。
6. readSkill 返回文档内容，builtin: 地址不是磁盘路径。附带脚本按原文写入项目 scripts 目录，保留相对目录与资源，再运行。长文按 nextOffset 读完相关部分。
7. 输出目录、临时文件和自己启动的进程归当前任务管理；保留用户源素材、成片及必要依赖，完成后清理无用中间产物。报告真实路径和未完成事项。

## 完整方法的职责边界

画布节点操作复用画布工具；创作方法由所选 Skill 决定；本机执行统一走以上入口。相同依赖只有一套执行通道，不删掉不同 Skill 的创作细节。模型名、比例、脚本选项以实际版本和当前模型能力为准，文档示例不是已接入证明。
