# 妙图执行说明（短剧漫剧全流程）

总控和子技能是为通用 Agent 环境写的。在妙图里执行时，下面几条说明各项规则落到画布、节点和工作区上的方式。正文里的「最高优先级」「硬门」描述的是创作流程本身，不能覆盖用户当前的要求、账号权限和节点实际支持的能力。

## 前置选项

- 总控要求开工前确认的选项（赛道、素材来源、模型版本、画幅、交付形态、段缝衔接、画风），按总控的格式一次列出来请用户选择。
- 用户已经在画布节点上选定的模型、比例、时长，算作已经指定，直接沿用，不再重复问。
- 用户明确说「按你的推荐」时，按总控给出的推荐项执行，并在回复里写明选了什么。

## 模型和参数

- 动手前先读用户选定节点的 `node:getConfig` 和 `getNodeTools` 返回的参数说明。模型、比例、时长、分辨率、首尾帧、参考图/视频/音频和声音开关，以节点实际配置为准。
- 正文写的 15 秒、30 秒、首尾帧限制、真人参考限制、语法标记和 H3 格式，和节点配置不一致时，以节点为准：保留动作、对白和叙事功能，按节点支持的时长拆段，用节点真实支持的字段。
- 节点里没有的模型只写方案，不擅自换模型。
- 模板里的 8K、16:9 等画面描述不代替实际输出参数。

## 素材形态

- 总控默认「只交付提示词，图由用户在外部平台生成」。妙图画布自带图片和视频生成节点，所以按用户的要求二选一：
  - 用户只要方案或提示词：按总控的 M0 / M1 交付，不生成。
  - 用户要求在画布上生成：用图片、视频节点生成，生成结果就是已入库素材（M2）；素材接线单里写节点 ID 和文件路径，不写「参考素材1」这类名字。
- 生成前用节点的 estimate 询价，在用户授权的范围内下单；返回结果不明时用同一个任务 ID 查询，不重新下单。生成、媒体和文件操作的细节读 `readSkill({name:"video-create", path:"references/miaoimg-tools.md"})`。
- 角色三视图、表情、服装、道具、场景布局等已有的可用资产直接复用，不重复生成。参考素材用原件，缩略图只用来预览。

## 交付形态

- md：写进文本节点或文档面板，一集或一段一个节点，按顺序从左到右排开，节点名写清集数和段号。
- 离线看板：需要运行总控附带的生成脚本，按下面「本机脚本」处理；不能运行时，在文档面板里用表格呈现同样的内容，并告诉用户看板没有生成。

## 本机脚本

- 正文里的机检和看板脚本（`scripts/*.py`）只能在桌面端、本机操作已授权时运行。先用 `readSkill` 读出脚本原文，用 `write` 保存到本次项目的 `scripts/` 下，保持原有文件名和相对目录，再执行；不要把 `builtin:` 开头的地址当成本机路径。
- 缺少 Python 等依赖时，读 `readSkill({name:"canvas", path:"references/local-tools.md"})`，只在用户的任务需要、且在授权范围内准备。
- 没有实际运行的检查，只能写成「人工审查」，不能写成「机检通过」。作者明确写了机器查不到的项（因果、人物动机、情绪），照样人工检查。

## 台账

- 资产编号（CHR、SCN、PRP 等）是项目内的逻辑编号，要对应到实际的节点 ID、文件路径和修订号。
- 资产图册记录素材和站位，连续性台账记录人物关系、伏笔和道具状态；同一件事只记一处，其他地方引用。

## 回复用户

用中文功能名和作品里的具体内容说明进展：做了什么、发现了什么、哪些还没做。平台热度、完播潜力、合规标签是创作参考，不要说成经过核实的平台规定或成功保证。
