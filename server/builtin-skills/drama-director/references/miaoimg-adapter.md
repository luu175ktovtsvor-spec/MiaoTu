# 妙图执行适配

四个入口共享此说明，读过后复用。本文负责工具、模型和文件。规则中的“最高优先级”“硬约束”描述创作流程本身，不能改写当前用户要求、账号权限或妙图当前模型能力。

## 阅读与规则归属

正文集中在 drama-director 的 references/production、references/real-action、references/fantasy-action、references/serial-writing。readSkill 截断时按 nextOffset 续读当前所需部分，不一次加载整套规则。文中的文件名按当前参考文件所在目录解析，references/... 是 drama-director 内的路径；先归一化相对链接，不把 .. 传入工具。素材路径以当前账号的工作区为准。

连续分集的大纲、人物关系、伏笔、道具和世界规则由 short-drama-factory 负责；drama-director 负责资产、分镜、段缝衔接和制作交接。写实动作按 real-combat-director，玄幻动作按 xuanhuan-combat-director，同一个动作段不并行套用多个相近引擎。通用编剧、单段短剧情和独立资产技能仍可单独使用；不重复创建同一剧本或资产。

## 模型与实际请求

先读取用户选定节点的 node:getConfig 和 getNodeTools 返回的 schema。模型、比例、时长、分辨率、首尾帧、参考图/视频/音频与声音开关以该实际配置为准。当前目录未提供的模型只可写方案，不擅自切模型。15/30 秒、首尾帧禁令、真人参考限制、语法标记与 H3 checkpoint 以当前节点实际配置为准；与配置不一致时，保留动作/对白/叙事功能，按可用段长拆分并使用真实支持的字段。

模板里的 8K、16:9 等画面描述不替代实际输出参数。已有节点明确的模型、比例与素材选择无需反复询问；确实缺少影响作品的选择再确认。平台热度、完播潜力、政策与合规标签是创作参考，不冒充经过核实的平台要求或成功保证。

只做方案时不生成。用户已明确要求执行生成时，按其授权范围读取当前服务端预计积分，不套用静态费用或批量默认下单。执行细节统一读取 readSkill({name:"video-create",path:"references/miaoimg-tools.md"})；复用同一任务 ID 查询结果，返回不明时不重新下单，原始产物写回当前账号画布并保留。

## 资产与连续性

CHR/SCN/PRP/Uxx 是项目内逻辑编号，必须关联实际节点 ID、文件路径与修订号，不依赖"参考素材1"等名称。一份正式资产图册、一份分集连续性台账各承担不同职责：前者记录素材与站位，后者记录人物关系、伏笔和道具状态；同一事实只维护一次，其他文件引用它。

角色三视图、服装、表情、动作、道具、场景布局、俯视图和视觉九宫格复用当前已有独立技能；制作总入口按任务需要 readSkill，不再复制另一套资产技能正文。4 View/站位/亲缘关系规范用来指定本项目交付，具体制作引用同一真实资产，不重复生成已有可用图。参考素材始终用原件；缩略图只供预览。

## 规则审查与看板

提示词按 C1–C20、H1–H12，单集按 E1–E23，全剧台账按 S1–S8 对应条目逐项规则审查；保留作者明确指出机器查不到的因果、人物动机和情绪问题。“机器通过”，不能声称没执行的脚本、素材生成或成片检查已经完成。

用已有画布节点和工作区文本呈现分镜看板、情绪节拍与问题卡。没有对应渲染工具时给可编辑表格，不编造 HTML 编译、图片曲线或音频分析结果。TTS、语音转写、字级对齐、自动人脸追踪须使用当前账号实际可用的工具；声音方案与实际生成/审听须区分。

## 用户可见内容

向用户展示中文功能名、作品、具体发现与当前完成情况。


## 桌面完整执行步骤

本机操作开启后，原文的 Python 检查、看板生成、音频分析、转写与素材处理步骤均可按已安装工具执行。先检查依赖与版本，不因过去缺少工具而跳过原方法；未找到时按统一工具说明，在用户任务授权范围内准备依赖。源指南中 references/ 指当前所属领域目录（production、real-action、fantasy-action 或 serial-writing），scripts/ 位于同一领域目录的 scripts/ 下。readSkill 读取脚本原文后，用 write 保存到本次项目 scripts/ 再执行，保留脚本文件名及相对资源关系；不把 builtin: URI 当成本机路径。没有实际运行的检查只能标为人工审查。


本机依赖统一读取 `readSkill({name:"canvas",path:"references/local-tools.md"})`；同一个工具供多个 Skill 共用。
