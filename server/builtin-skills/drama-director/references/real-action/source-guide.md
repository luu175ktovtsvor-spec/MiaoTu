> 每个任务动笔前必须先完成 A、B 两道创作锁。任一项用户未指定 = 任务不开始，禁止默认跳过。

## 一、 铁律（任何环节不得违反）

1. **无静止表演铁律（总纲）**：AI 视频没有"静止表演"能力。"对峙/蓄势/悬停/站立/特写定格"类静止段一律渲染成呆立——**一切情绪与蓄力必须在运动中完成**（边打边蓄、后撤中蓄、甩剑转身时带神态）。唯一允许的定格 = 命中瞬间 1~2 帧微停顿（Hit-Stop，仅 2.5）。**R1 例外**：允许克制收势或悬念收尾（见 二）。
2. **真人脸红线（官方硬约束）**：Seedance 系列**不支持上传含真人人脸的参考图/视频**——所有角色资产参考图必须为动漫/CG/绘画风格。写实感靠提示词的"实拍影视质感/物理真实"描述达成，不靠真人照片参考。
3. **台词/音效默认视频内出**：台词与音效默认写入提示词由模型生成（2.5 官方字符、2.0 文字描述），**禁止默认降级后期配音**；仅用户明确逐次说"不出台词/走后期"才走后期。
4. **默认只出提示词不出图**：一律不调用出图工具直接生成图片（资产图/参考图/关键帧同理，只给提示词）。用户明确说"出图"才执行。
5. **合规转译（不承诺通过率）**：写实打斗直白血腥词汇会被平台拦截。血腥/断肢/致命词必须按 `references/impact-physics.md` §五 转译为物理受力描写（如"打断骨头"→"拳峰接触点肌肉剧烈凹陷波纹、骨骼受力脆响"）。以各平台实时审核政策为准。
6. **不套特效词**：R1 写实打斗禁止"特效生长/双色粒子对冲/光波对轰/冲击波法阵"等玄幻写法；气爆/光效类描写**默认弱化**，以真实受力反馈与环境破坏为主。

## 二、 R1 写实克制档定义（先定档再动手）

| 项 | R1 写实克制（本包唯一档位） |
|---|---|
| 适用 | 写实格斗 / 警匪追逐 / 悬疑暗杀 / 喜剧打斗 / 儿童向 |
| 开局 | 不强制硬撞，**1.5 秒内发生攻防接触即可**（第一帧建议双人同框中近景，禁远景慢热铺垫） |
| 近景机枪对招 | 可选（有则用序列化招式链） |
| 气爆/特效 | 不强制，以**真实受力反馈**为主（肌肉凹陷/骨骼脆响/脚步犁地/环境破坏） |
| 终结收尾 | **允许克制收势或悬念收尾**（如反派踉跄后退、主角收拳喘气、胜负留白），不强制高潮收镜 |
| 升格/慢镜 | 默认禁用（实测破坏节奏）；仅用户明确要求且 ≤1s 可用 |
| 站桩式对打 | **严禁**（所有招式必须挂在步法位移上；禁套路起承转合、禁两人站定轮流出招） |
| 打斗风格最低线 | 快慢呼吸交替，同节奏连续 ≤5 秒 |
| **多人同场（2~4 人）** | 走 `references/multi-opponent-rules.md`（★多人唯一真源）：主角唯一锚点 · 同镜交手 ≤3 人 · 三拍轮转禁站等 · 1v2 用 4~5 镜 / 1v3 用 5~6 镜 |

**R1 完播潜力评分**（启发式自检，非平台预测）：

$$\text{评分} = 0.20 \times \text{开局吸引力} + 0.30 \times \text{节奏呼吸} + 0.25 \times \text{运镜丰富度} + 0.25 \times \text{情绪拐点}$$

- 同运镜 ≤2 秒，同景别 ≤3 秒（15 秒内 5~8 次精准切换，近景/特写除外）；
- 8~12 秒区间出现一次局势逆转/破防爆发/破绽抓取（情绪拐点）；
- 节奏骨架：快慢交替，避免全程同一强度平推（单场战斗按节拍弧推进：接敌→试探→施压→破防→逆转/收势）。

## 三、 六步工作流（Asset-First 精简版）

```text
S1 定档锁参 → S2 拆招设计 → S3 镜头分镜 → S4 投喂封装 → S5 机检 → S6 质检交付
```

1. **S1 定档锁参**：A·模型版本二选一 → B·画幅三选一 → C·交付形态（默认③）。题材/人物/场景/时长确认。
2. **S2 拆招设计**（`references/kinetic-chain-11.md` + `references/real-fight-techniques.md`）：每记关键重击用 11 环动力链推导；招式从真实格斗库选取（禁"挥拳打去/放光波"等抽象描述）；写入角色风格（如"半步崩拳"“泰式扫踢"）。连接招/过渡招写清起点、受力点、状态继承即可。**判据门**：用户点名某门武学、或要求「招式细一点」→ 必读 `references/martial-styles-extended.md`（19 门武学核心 12 式 / 36 路腿法 / 擒拿 36 式 / 命名连招库 / 兵器写实移植）；需要连招组合、踢击部位、情绪拐点、化劲、上下肢配合等具体技法 → 必读 `references/technique-combo-library.md`。 **⚠️ 两个招式库只取神不取形**：仅取「招式名/外形特征、劲力原理与发力方向、打击部位与受力反馈」三样；**衔接与节奏一律以本包为准**（`kinetic-chain-11.md` 11 环动力链 + `r1-combat-core.md` §三 节拍弧 / §八 节奏硬口径）——禁照搬库内 12 式套路顺序与「A→B→C」箭头链，禁站桩式对打，禁套路式起势/收势成镜。**多人判据门**：任务出现「两人以上同场交手 / 以少打多 / 一打多 / 围攻 / 群战 / 2v2 / 3v3」→ **必读** `references/multi-opponent-rules.md`（★多人战斗唯一真源：主角唯一锚点 · 多轴管理 · 三拍轮转禁站等 · 破围点节拍弧 · 防分身）。
3. **S3 镜头分镜**（`references/camera-action-specs.md` + `references/defense-evasion-rules.md`）：镜头规格五要素；空间两大铁律；景别阶梯；防守三态与闪避大幅化；受击镜头工具箱；三手法六式衔接。镜长由剧情倒推，**禁机械等分**，快慢呼吸交替。多人同场时景别策略按 `references/multi-opponent-rules.md` §六（人越多镜头越收紧 · 特写禁 ≥3 人同焦 · 过肩带出第二人）。
4. **S4 投喂封装**（`references/render-adapters.md`）：七段式主格式 + 一行式站位声明 + 镜行原生写法 + 时长分配（2.5 ≤15s/组推荐、2.0 ≤15s 按剧情倒推）+ 声音行 + 接续状态 + 负面词。
5. **S5 机检**：字数门禁（中文 ≤500 字/组，**只计【时间轴分镜】段正文**，口径见 `references/render-adapters.md` §六）；同段 ≥4 镜且同值镜长占比 ≥70% 即重排；无"静止段/抽象词/顿挫词（2.0）/首尾帧（2.0）/特效词"残留；镜行必带 `声音：` 与 `台词：`。
6. **S6 质检交付**：P0 阻断项（画幅一致性/越轴/静止段/后台词外显/字数超限）→ P1 结构项（节奏呼吸/景别阶梯/情绪拐点）→ P2 建议项（音效层次：对白 0dB > 物理音效 -6dB > BGM -14dB）。**改动后复验铁律**：修改类任务按「局部验证→联动冲突检查→全量审核」三步闭环，交付附《改动复验报告》。
