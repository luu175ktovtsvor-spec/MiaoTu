# Performance sound and additional sound

Keep accepted performance audio meaningful while the picture changes. A generated video can already contain speech, room tone and action sound; avoid duplicating those tracks. Add a separate sound only for a distinct role. Source audio, incoming speaker, music bed and graphic event may share time with different boundaries. Realize available editing through the actual FFmpeg schema and retain what has not been audibly reviewed.
