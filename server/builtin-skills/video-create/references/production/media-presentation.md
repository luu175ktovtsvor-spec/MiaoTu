# Media presentation

Display time and source playback are distinct. A shorter window can use part of a clip; a longer window does not automatically stretch, loop or hold it. Choose the end for the thought, action and reading time. Preserve native speed when action matters, and make any intentional retiming explicit. Source location sound can contribute to the mix; merely showing a picture does not replace the narrator’s performance. Node preview fills its existing frame at native aspect without altering the original video.
