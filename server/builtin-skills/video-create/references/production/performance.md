# Presenting performance

Accepted performance retains its speech, gesture, gaze and local time when the picture changes size, position or visibility. A small presenter and full-screen evidence can share the passage; B-roll may cover the picture while performance sound continues. Use the actual accepted media, measured trim and placement. There is no separate Performance renderer in the application; realize supported arrangements through real nodes/media composition.

实际工具、参数、账号路径、费用和限制见 [妙图工具说明](../miaoimg-tools.md)。
