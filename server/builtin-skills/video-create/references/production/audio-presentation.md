# Audio presentation

Choose gain, fade, trim, overlap and duration for clarity and the event they support. Music should not mask words; a sound effect should answer an actual movement or reveal. There is no default stock library or independent sound-generation service here. Use supplied/accepted audio, or detect a genuinely available node before offering generation. Do not equate a waveform or audio codec with having heard the result.
