# 妙图桌面界面

本目录只维护桌面界面、画布及节点组件。完整产品由上一级 Electron 宿主管理账号会话、本机项目、文件、Agent 和生成任务；不在这里启动另一套云端服务或数据库。

从仓库根目录运行：

```sh
npm run setup
npm run dev
```

`npm run build` 构建界面和宿主到 `desktop/.app`，不生成安装包。构建统一使用本目录的 `index.html`；不再保留内容相同的第二个桌面 HTML 入口。

仅检查界面代码时，可从仓库根目录运行 `npm run desktop:renderer`，或在本目录运行 `npm run dev`。它只有 Vite 与静态资源，API、MCP 和健康请求会明确提示需要完整桌面，不能用它判断登录、任务、文件和本机工具是否可用。该命令不启动图片/管理/档案 API，不读取模型或支付密钥，不创建业务数据库。

在本目录先运行 `npm run build` 后，可用 `npm run preview` 查看静态构建；这仍是界面检查，不提供原生宿主。终端输出的地址默认绑定 `127.0.0.1`，可通过 Vite 的 `--port` 和 `--strictPort` 指定端口。

官网、管理后台和服务端单独开发使用仓库根目录的 `*:web` 命令，配置及部署规则见根目录 README 和 AGENTS.md。公开灵感库数据只由官网/API 准备流程下载，不属于桌面依赖安装流程。
